# Crochet Quest

A whimsical platform adventure through a crocheted world, built with Python and Pygame.

## Setup

Python 3 is required.

### Activate the virtual environment

```bash
source .venv/bin/activate
```

When the environment is active, the terminal prompt should begin with `(.venv)`.

### Install the required packages

```bash
python -m pip install -r requirements.txt
```

## Start the game

```bash
python main.py
```

## Controls

- Move left: **Left Arrow** or **A**
- Move right: **Right Arrow** or **D**
- Close the game: close the game window
- Stop from the terminal: **Control+C**
